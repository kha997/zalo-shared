# SDK evidence and remaining risks

Scope: npm zca-js2.2.0 development baseline. The application connector is not enabled. `PASS` below is limited to the stated offline boundary; it does not establish platform authorization or real-account safety.

| Boundary / risk | Demonstrated evidence | Remaining gate |
| --- | --- | --- |
| Reproducible artifact | PASS: exact version, registry/lock SHA512 and archive SHA256 recorded; published ESM/CJS models exercised with network/write/process guards. | Registry gitHead differs from research snapshot. No reproducible source-to-binary equivalence is established. |
| Secret-bearing SDK errors | PASS at facade boundary: injected SDK/store errors become fixed errors without cause; raw API/context/cookie jar excluded. | Upstream can stringify its context. Future wiring must use the facade and prohibit raw SDK errors in logs. |
| Session writes after timeout | PASS within one facade: deferred-write regression proves serialized commits and suppression of expired queued writes. | In-flight writes cannot be undone. Separate facade/process owners still require exclusive external ownership; this is not global fencing. |
| Text-only boundary | PASS: objects, attachment/path objects, Buffers, invalid peers/types and oversized text are rejected before SDK invocation. | Real sends/receipts remain UNPROVEN. Media requires a separately tested interface, not widening this method with arbitrary objects. |
| Shared-listener restart | OPEN, source-proven hazard: upstream old-socket close can reset a newer socket; existing transport reuses its listener. | Fresh isolated API/listener generations or confirmed-close serialization, lifecycle regression and real invalidation/reconnect tests before enabling. |
| Durable inbound / phone echo | NOT IMPLEMENTED in the connector. Existing synchronous callback does not await DB persistence; SDK client IDs are generated internally. | Bounded observed ingress, transactional dedup, pending-echo reconciliation and truthful native-phone attribution. Never match only text/time or infer retry safety. |
| Media partial effects / hang | OPEN, source-proven hazard: text can precede failed uploads; callback expiry deletes an entry without settling the pending upload promise. | Per-component durable attempt markers, bounded private bytes/metadata, unknown outcomes without automatic resend, actual peer receipt and restore tests. |
| Dependency maintenance / licensing | Crypto-js4.2.0 is deprecated/unmaintained.31 resolved package paths and32 supplied notice files are recorded. Spark-md5 references a missing MIT LICENSE2; supplied WTFPL is preserved. | Advisory/signature evidence is a dated gate, not maintenance assurance. Production promotion, dependency policy, licensing and original-code license choice require review. |
| Login, phone coexistence and account restriction | UNPROVEN: no real login, QR, account, phone or customer data was used. | Dedicated legitimate account/phone/peer, explicit private Owner participation/risk consent, four physical workstations and7–14day low-volume pilot. Passing tests cannot establish ban safety. |
